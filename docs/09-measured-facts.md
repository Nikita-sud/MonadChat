# Что измерено на живом тестнете (29 августа 2026)

Всё ниже — результат запусков против `https://testnet-rpc.monad.xyz`, а не чтения документации.
Часть выводов расходится с тем, что написано в других файлах `docs/`; верить следует этому файлу.

## 1. Reserve Balance ограничивает чат жёстче, чем кажется

**Эксперимент** (`scripts/` → пять транзакций подряд с аккаунта с балансом 5 MON):

```
tx 0: status=success   block 57898190
tx 1: status=reverted  block 57898191
tx 2: status=reverted  block 57898191
tx 3: status=reverted  block 57898191
tx 4: status=reverted  block 57898191
баланс: 5 → 4.98829 MON
```

**Вывод.** У аккаунта с балансом < 10 MON проходит одна тратящая транзакция раз в k=3 блока
(«emptying transaction»), остальные **ревертятся, но газ платят**. Прочтение официальной
документации, будто правило про revert ниже 10 MON относится только к делегированным
EIP-7702 аккаунтам, — **неверно**. Файл `02-monad-vs-ethereum.md` §2 был прав.

**Следствие для продукта.** Сообщения нельзя слать параллельно. В `web/src/lib/sender.ts`
стоит последовательная очередь с паузой 1700 мс (4 блока). Зритель этого не замечает,
но ни одно сообщение не сгорает впустую.

**Побочная выгода.** Это анти-спам на уровне консенсуса сети, а не на нашем сервере:
один кошелёк — не чаще одного сообщения в ~1.2 с, и обойти это нельзя.

## 2. Реальная стоимость газа

| Операция | gas limit | Цена при 102 gwei |
|---|---|---|
| Перевод MON | 21 000 | 0.00214 MON |
| `sendMessage` | ~118 000 | **0.0121 MON** |
| `setRoom` | ~75 000 | ~0.0077 MON |
| Деплой контракта | 567 436 | 0.0579 MON |

Газ списывается по `gas_limit`, поэтому буфер к оценке — **7.5 %**, не ×2
(`gasMargin()` в `web/src/lib/chain.ts`).

**Следствие.** Цена сообщения 0.01 MON была бы **дешевле собственного газа**.
Дефолт в кабинете стримера — **0.05 MON**, при ней газ составляет ~19 % от суммы.

## 3. Лимит публичного RPC — 25 запросов в секунду, а не 50

Ошибка: `429 · requests limited to 25/sec`. Бэкфилл из 12 параллельных `getLogs`
выбивал квоту, ронял загрузку истории **и заодно рукопожатие WebSocket** — из-за чего
казалось, что сокет не работает в браузере (он работает, проверено отдельно).

Решение — батчинг JSON-RPC в `chain.ts`: viem склеивает параллельные вызовы в один
HTTP-запрос (`batch: { wait: 20, batchSize: 20 }`) плюс ретраи на 429.

## 4. WebSocket в браузере работает

`new WebSocket('wss://testnet-rpc.monad.xyz')` подключается за ~90 мс и отвечает на
`eth_blockNumber`. Подписка `logs` доставляет события в другую вкладку — проверено на
оверлее, который сообщений не отправлял, а получил их из цепочки.

## 5. Кран отдаёт 1 MON за вызов и доступен программно

```
POST https://agents.devnads.com/v1/faucet
{"chainId":10143,"address":"0x..."}
→ {"txHash":"0x…","amount":"1000000000000000000","chain":"Monad Testnet"}
```

Авторизации нет. Повторный вызов в коротком окне возвращает **тот же** txHash, то есть
докачать кошелёк выше 10 MON краном не получится. Ходить нужно **с сервера**
(`web/src/app/api/faucet/route.ts`) — у крана нет CORS-заголовков для браузера.
