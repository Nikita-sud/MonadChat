# MonadChat — MVP за 5 часов

**Идея:** онлайн-чат для стримеров на Monad. Зритель платит MON за каждое сообщение
(«superchat on-chain»). Сообщение — это транзакция в контракт; деньги уходят стримеру,
текст живёт в event'е, фронт и OBS-оверлей читают события в реальном времени по WebSocket.

Почему это хорошо ложится на Monad: блок 300–400 мс, финальность ~0.8 с → сообщение
появляется в чате почти мгновенно после подписи. Это и есть демо-фишка.

| Слой | Выбор | Почему |
|---|---|---|

| Оверлей | Отдельная страница `/overlay/[streamer]` для OBS Browser Source | Видно на стриме, wow-эффект |
| Хостинг | **Vercel (обязательно, бесплатный `*.vercel.app` + HTTPS)** — первый деплой сразу после скелета фронта, домен не нужен | См. `08-deploy-hosting-and-demo.md` |

## Архитектура

```
Viewer (MetaMask) ──sendMessage{value}──▶ StreamChat.sol ──MON──▶ Streamer wallet
                                              │
                                              └── emit MessageSent(streamer, sender, amount, text, ts)
                                                        │
        ┌───────────────────────────────────────────────┴──────────────────────┐
        ▼                                                                      ▼
  /room/[streamer]  (чат зрителя, wagmi + WS logs)              /overlay/[streamer] (OBS, только чтение)
```

Контракт — один файл (см. `05-contract-design.md`):
- `setRoom(uint256 price, string streamUrl)` — стример задаёт цену и где он стримит (`twitch:xqc` / `youtube:VIDEO_ID` / `kick:channel`); price 0 = комната закрыта
- `sendMessage(address streamer, string text) payable` — `msg.value >= price`, деньги сразу пушатся стримеру, `emit MessageSent`
- Тир подсветки на фронте по `amount` (1x, 5x, 10x цены → обычное / highlighted / pinned)

Ни одной строки состояния, кроме `price[streamer]` и `earned[streamer]` — всё остальное в event'ах.

## Сценарий демо (2 минуты)

Позиционирование: **мы не стриминговая платформа — мы платный on-chain чат-слой поверх Twitch/YouTube/Kick.** Стример продолжает стримить где стримил, добавляет наш оверлей в OBS и постит ссылку на комнату. Подробно: `08-deploy-hosting-and-demo.md`.

0. Заранее: `setRoom(0.01 MON, "twitch:<канал, который сейчас в эфире>")` — свой тестовый стрим из OBS (лучший вариант) или любой живой топ-стример (с оговоркой «в проде деньги идут стримеру после Twitch OAuth»).
1. Открыть `/overlay/0xСТРИМЕР` в OBS как Browser Source (или второе окно во весь экран).
2. Зритель на `https://monadchat.vercel.app/r/0xСТРИМЕР`: слева реальный эфир, справа чат. Подключает MetaMask, пишет «gg», платит 0.01 MON → через ~1 с сообщение в чате и на оверлее поверх стрима.
3. Второй зритель платит 0.1 MON → сообщение подсвечено «gold», закреплено сверху.
4. Показать на explorer: tx, событие, баланс стримера вырос.
5. Показать `dashboard` стримера: заработано X MON, цена меняется одной транзакцией.

## Гочи Monad, которые могут сломать демо (детали в `02-monad-vs-ethereum.md`)

1. **Газ списывается по `gas_limit`, не по фактическому расходу.** Не ставить gasLimit «с запасом ×3» — задать явный лимит (`estimateGas` × 1.075) или захардкодить (~60–80k для `sendMessage`).
2. **Reserve Balance = 10 MON.** Если у аккаунта < 10 MON, транзакция считается «emptying» и проходит только если в предыдущих 3 блоках (~1.2 с) от этого аккаунта не было других tx. Для чата это естественный rate-limit, но **не спамить из одного кошелька быстрее 1 tx/1.5 с** на демо. Кран даёт мало MON → у тестовых кошельков будет < 10 MON.
3. **`eth_getLogs` — максимум 100 блоков на запрос** на публичном RPC (QuickNode). История чата = только последние ~30 секунд через getLogs; для «полной истории» либо крутить окно 100 блоков в цикле, либо держать сообщения в памяти фронта. Для демо достаточно.
4. **`latest` = Proposed (спекулятивный).** Для чата это ок (показываем сразу), для «заработано» можно ждать `finalized`, но для демо не критично.
5. **`eth_maxPriorityFeePerGas` возвращает захардкоженные 2 gwei;** базовая комиссия min 100 gwei. wagmi/viem справятся сами, не переопределять руками.
6. **Нет мемпула** — `eth_getTransactionByHash` вернёт `null`, пока tx не в блоке. Ждать `waitForTransactionReceipt`, не «pending»-состояние.
7. **Testnet был сброшен 2025‑12‑16** — старые адреса из чужих статей могут не существовать.

## Что взять из шаблонов, а что написать самим

- Контракт: свой (30 строк). Шаблон foundry-monad нужен только ради готового `foundry.toml`.
- Фронт: `create-next-app` + wagmi — быстрее, чем разбирать Privy PWA-шаблон. Privy/Reown — только если захочется логина по email (не нужно для демо).
- Индексеры (Envio/Goldsky/Ghost) — **не нужны**, WS-подписка + event'ы покрывают всё.
- x402 — не подходит для этой модели (это HTTP-пейволл в USDC, а не on-chain чат), упоминаем как «дальнейшее развитие».
