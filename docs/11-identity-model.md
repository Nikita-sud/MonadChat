# Как устроены кошельки и роли на сайте

Одна идея: **порог входа — ноль, а свой кошелёк — по желанию, не по требованию.**

## Зритель

| Режим | Как работает | Зачем |
|---|---|---|
| **Браузерный кошелёк** (по умолчанию) | Ключ создаётся в localStorage при первом заходе. «+1 MON» наливает из крана. Сообщения подписываются локально и уходят без единого попапа через быструю очередь (локальный nonce, фиксированные комиссии, пауза 1.7 с под reserve balance). | Жюри и случайный зритель пишут через 10 секунд после клика по ссылке. |
| **MetaMask как заправка** («top up from MetaMask») | Кнопка в футере чата: одно подтверждение — 0.5 MON переезжают из MetaMask в сессионный кошелёк, дальше все сообщения летят без попапов по быстрому пути. MetaMask ищется по EIP-6963 (адресно, мимо конфликтующих кошельков-расширений). | Один попап на всю сессию вместо попапа на каждое слово. |

Детали, о которых легко забыть:
- Отказ в попапе — «Cancelled in the wallet», это не ошибка; «request already
  pending» — подсказка открыть окно MetaMask и завершить висящий запрос.
- MetaMask бросает голые объекты {code, message}, а не Error — обработчик ошибок
  обязан читать оба вида, иначе на экране «[object Object]».
- В useChat остался код отправки от имени MetaMask (SendIdentity) — из интерфейса
  убран в пользу сессионного кошелька, вернуть — одна строка в Chat.tsx.

## Стример

| Режим | Как работает |
|---|---|
| **Браузерный кошелёк** (по умолчанию) | Комната привязана к ключу браузера. Быстро, но выручка живёт в localStorage этого браузера. |
| **MetaMask** | Кнопка «connect MetaMask» в кабинете: сеть Monad Testnet добавляется сама, setRoom подписывается кошельком, выручка капает прямо в него. |

## Поле «где стримишь»

Принимает что угодно: `lofigirl`, `twitch.tv/lofigirl`, `https://youtube.com/watch?v=ID`,
`youtu.be/ID`, `kick.com/channel` — `normalizeChannelInput` сводит к голому ID при
сохранении, а `embedUrl` нормализует и уже сохранённые в контракте значения, поэтому
старые комнаты с полной ссылкой в поле чинятся без транзакции.

## Чего сознательно нет

- WalletConnect/RainbowKit — попап-инфраструктура ради попапов; injected-провайдера хватает.
- Вывода средств — деньги уходят стримеру push-переводом в момент сообщения.
- Бэкенда — обе роли разговаривают с контрактом напрямую.
